# Лабораторная работа 2

## Требования к окружению
Для корректной работы скрипта db_init.bat на компьютере должны быть установлены:
- Python версии 3.x
- Утилита командной строки SQLite (sqlite3)

## Описание процесса
1. Скрипт make_db_init.py считывает исходные данные из файлов users.txt, movies.csv, ratings.csv, tags.csv.
2. Он автоматически извлекает год из названия фильма и генерирует SQL-скрипт db_init.sql с командами DROP TABLE, CREATE TABLE и INSERT INTO.
3. Скрипт db_init.bat запускает утилиту Python, а затем выполняет сгенерированный SQL-скрипт через sqlite3, создавая и заполняя базу данных movies_rating.db.
