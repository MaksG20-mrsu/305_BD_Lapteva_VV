\# Лабораторная работа 1



\## Структура файлов данных



\### users.txt

Файл разделен символом `|`. Заголовки отсутствуют.

\- Поле 1: id (идентификатор пользователя)

\- Поле 2: name (имя)

\- Поле 3: email (электронная почта)

\- Поле 4: gender (пол)

\- Поле 5: date (дата, вероятно, дата рождения или регистрации)

\- Поле 6: occupation (профессия)



\### movies.csv

Файл разделен запятыми.

\- movieId: идентификатор фильма

\- title: название фильма (с годом выпуска)

\- genres: жанры фильма (разделены символом `|`)



\### ratings.csv

Файл разделен запятыми.

\- userId: идентификатор пользователя

\- movieId: идентификатор фильма

\- rating: оценка (вещественное число)

\- timestamp: временная метка (unix timestamp)



\### genres.txt

Текстовый файл, содержащий список жанров. Каждая строка — один жанр (без заголовков и разделителей).



\### occupation.txt

Текстовый файл, содержащий список профессий. Каждая строка — одна профессия (без заголовков и разделителей).



\### tags.csv

Файл разделен запятыми.

\- userId: идентификатор пользователя, оставившего тег

\- movieId: идентификатор фильма

\- tag: текстовый тег

\- timestamp: временная метка (unix timestamp)
